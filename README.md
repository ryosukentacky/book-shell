# 読書学習ライブラリ（全文保持版）

GitHub Pagesのリポジトリ直下に、このZIP内のファイルをすべて配置してください。

- `index.html` / `app.js` / `style.css`: サイト本体
- `index.json`: 本棚一覧
- `book-001.json`: 『本を読む人はうまくいく』の既存データ
- `book-002.json`: 『スマホ時代の哲学』の第1章1項から最後までの全12解説

第2冊はPDF 94〜176ページから抽出し、参照番号のみ削除しています。解説導入、A/B/C/D、問題、解答、復習などを省略せず保持しています。第1冊は以前のデータを引き継いでいるため、原本との完全照合は別途必要です。

注意: 読みやすさのためPDFの行末折り返しを一部結合しています。PDFのテキスト抽出に由来する誤字・改行は残る場合があります。著作権のある資料は公開範囲にご注意ください。
